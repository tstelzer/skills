# Actionlint

Add [`reference/flake.fragment.nix`](./reference/flake.fragment.nix) to the development shell. Non-Nix Linux and
macOS users install Actionlint with their system package manager or another method they control.

Merge [`reference/just.fragment`](./reference/just.fragment) into the repository's `check` recipe. Add the command
when Actionlint is available in the project environment. Actionlint needs no repository config for the baseline.
