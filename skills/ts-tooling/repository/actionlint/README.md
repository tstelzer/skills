# Actionlint

Add [`reference/flake.fragment.nix`](./reference/flake.fragment.nix) to the development shell. Non-Nix Linux and
macOS users install Actionlint with their system package manager or another method they control.

Append [`reference/just.fragment`](./reference/just.fragment) to the repository `justfile`. Actionlint needs no
repository config for the baseline.
