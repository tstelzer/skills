# Vite

Install Vite directly for TypeScript applications and libraries that use it for development or builds.

Merge [`reference/package.fragment.jsonc`](./reference/package.fragment.jsonc) into `package.json`. Add a
`vite.config.ts` only when the project needs settings beyond Vite defaults.

Append [`reference/just.fragment`](./reference/just.fragment) to the repository `justfile` when it uses Just.
