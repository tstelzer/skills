# Control flow

Keep the normal path easy to follow. Choose the construct that exposes the work and the exit conditions.

| Need | Read |
| --- | --- |
| Extract a value, return early, or match states | [Branches](./branches.md) |
| Traverse, transform, or collect values | [Loops and iterators](./iteration.md) |
| Accept callbacks or capture values | [Closures](./closures.md) |

For propagating failures, read [errors](../errors/propagation.md).
