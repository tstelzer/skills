# Types

Use types to state which values and states the program accepts.

| Need | Read |
| --- | --- |
| IDs, units, missing values, or mutually exclusive states | [Model values](./modeling.md) |
| Preserve partial output or unknown protocol values | [Model values](./modeling.md) |
| Enforce valid construction, use builders, or encode transitions | [Construction](./construction.md) |
| Convert values and implement standard traits | [Conversions](./conversions.md) |

For numeric ranges, read [numbers](../numbers/index.md).
For validated deserialization, read [Serde validation](../serde/validation.md).
