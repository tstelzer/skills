---
name: ts-simple
description: Use very simple language. Only explicitly triggered by user.
---

Make all prose in this task easy to read. Apply this skill alongside any other skill the user invokes.

- Use the simplest words that keep the full meaning.
- Write short sentences. Make one point at a time.
- Say what happens. Cut abstract phrases and extra detail.
- Keep exact names for code, commands, and files. Explain needed jargon in plain words.
- Before sending, rewrite any sentence that takes effort to read.
