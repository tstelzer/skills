# Effect library documentation

This handbook vendors Effect v4 guidance from the Effect monorepo and adds
application rules identified through local implementation reviews.

Start with this documentation. When a task needs an API detail it does not
cover, inspect the matching Effect v4 source checkout. Do not use `node_modules`
as documentation because it may target another Effect version.

**Note**: The examples in this documentation contain comments for illustration
purposes. In practice, you would not include these comments in your code.
